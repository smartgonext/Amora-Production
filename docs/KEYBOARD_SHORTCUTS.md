# SmartGoNext Universal ERP — Keyboard Shortcut Reference Sheet
### Quick Navigation & Hotkeys Guide

SmartGoNext ERP is designed to be fully operable by keyboard alone. Below is the list of universal and module-specific shortcuts supported across the SaaS and desktop application interfaces.

---

## 1. Global Navigation Shortcuts

These hotkeys work on any screen:

| Keyboard Shortcut | Action |
| :--- | :--- |
| `Alt + D` | Navigate directly to the main **Dashboard** |
| `Alt + P` | Open the **Products Catalog** page |
| `Alt + C` | Open the **Customer Registry** page |
| `Alt + B` | Open the **POS Billing Terminal** |
| `Alt + I` | Navigate to **Inventory Ledger** |
| `Alt + F` | Navigate to **Finance / Treasury** |
| `Alt + S` | Open the **System Settings** page |
| `/` (Forward Slash) | Focus the **Global Search** input |
| `Ctrl + K` | Open the **Command Palette** dialog |
| `Esc` | Close any active modal, dropdown, or overlay |

---

## 2. POS Billing Terminal Shortcuts

These hotkeys accelerate checkout operations:

| Keyboard Shortcut | Action |
| :--- | :--- |
| `F2` | Quick search and select customer dropdown |
| `F4` | Focus the **Item Search/Add** line input |
| `Ctrl + +` (Plus) | Increase the quantity of the currently selected row |
| `Ctrl + -` (Minus) | Decrease the quantity of the currently selected row |
| `F8` | Open the **Payment Method / settlement** dropdown selection |
| `F9` | **Submit & Print Invoice** (Complete sale instantly) |
| `Ctrl + Delete` | Clear all draft line items |

---

## 3. Data Grid Table Shortcuts

These hotkeys help navigate through reports and record logs:

| Keyboard Shortcut | Action |
| :--- | :--- |
| `Arrow Down` | Select the next row in the table |
| `Arrow Up` | Select the previous row in the table |
| `Page Down` | Navigate to the **Next Page** |
| `Page Up` | Navigate to the **Previous Page** |
| `Ctrl + F` | Focus the table's search filter field |

---

## 4. Modal Dialog Shortcuts

* Use `Tab` to cycle focus forward through inputs.
* Use `Shift + Tab` to cycle focus backward.
* Press `Enter` to submit the form or confirm the action.
* Press `Esc` to close/cancel the modal.
